# DRC1200
DRC1200 software remote control implemented with wxWidgets. 

This application is intended for use with RTZ Audio DTC-1200 transport and STC-1200 timer/locator controllers for vintage Ampex MM1200 analog studio recorders. DRC1200 is a TCP/IP GUI application that runs on linux and Windows operating systems via wxWidgets GUI and toolkit interface libraries.

Visual Studio is used to build the application for Windows, the project also contains a Windows Setup project which is used to build the DRC1200.msi installer file. The wxWidgets GUI and application framework must be installed prior, visit the wxWidgets website to download and install the wxWidgets C++ development framework.

Code Blocks is used to build the application for Linux, the project also contains a Flatpak Builder project which is used to build the installer. The wxWidgets GUI and application framework must be installed prior, visit the wxWidgets website to download and install the wxWidgets C++ development framework.
